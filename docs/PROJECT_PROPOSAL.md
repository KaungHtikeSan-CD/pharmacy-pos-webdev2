## Project Description

Pharmacy POS System is a web-based pharmacy management system designed for a small or mid-range pharmacy. The system helps pharmacy staff manage medicine stock, record wholesale medicine orders, confirm arrived items, process customer sales, and review purchase history.

The project will be developed using Next.js and MongoDB. It focuses on daily pharmacy operations such as adding products, ordering products from wholesale shops, updating stock after arrived orders, selling products by box or card, and checking sales history.

## Project Objectives

- Create a pharmacy POS system using Next.js and MongoDB.
- Provide CRUD operations for at least three main data models.
- Manage medicine stock with search and low stock checking.
- Record wholesale orders and confirm whether ordered items have arrived.
- Automatically update stock when an order is confirmed as arrived.
- Support POS checkout using barcode or product code.
- Record purchase history by date.
- Provide dashboard summaries for sales, orders, stock, and top-selling products.

## Main Data Models

- Product / Stock
- Order
- Sale / Purchase

## Expected Outcome

The final system will be a working pharmacy POS web application deployed on a VM. The source code will be available on GitHub with a README file, screenshots, production URL, and demo video.
